
# MUSKERTEERS – KYUCampusGrade

## Project
SPC 2401: Distributed Operating Systems

A distributed grading service implemented using Java RMI.

## Features
- Submit student marks
- Retrieve student marks
- Publish marks
- Student notification subscriptions
- Concurrent request handling
- Failure handling and retry mechanisms

## Technology
- Java
- Java RMI
- Maven
- JUnit
- Git and GitHub

## Project Structure
- src/: Application source code
- tests/: Automated tests
- docs/: Reports and diagrams
- evidence/: Screenshots, logs and test results
- scripts/: Helper scripts

## Development Workflow

1. Developers create feature branches.
2. Changes are committed with meaningful messages.
3. Another team member reviews the changes.
4. Approved changes are merged into main.
5. All implementation and testing evidence is maintained.
